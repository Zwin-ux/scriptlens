Privacy and disclosure ScriptLens
Overview Design system Support GitHub Issues
Effective September 27, 2026

ScriptLens runs entirely on your device.

ScriptLens is a Chrome extension for desktop youtube.com/watch pages. Its single purpose is to analyze the writing style of YouTube transcripts for AI-like patterns. This policy explains what the extension accesses and what it stores. ScriptLens has no servers of its own, so nothing you analyze is sent to ScriptLens.

Local scoring No ScriptLens servers No ad-tech use
Default path

Scoring runs on-device.

The normal ScriptLens flow evaluates transcript content inside the extension runtime on your device.

Network

Only YouTube is contacted.

ScriptLens loads captions for the video you are watching directly from youtube.com, the same way the YouTube player does. It never contacts any other server.

User control

Settings and data stay manageable.

You can change settings, clear extension storage, or remove the extension at any time.

Information accessed

What ScriptLens reads

  • Desktop YouTube watch pages on https://www.youtube.com/*
  • Transcript metadata and transcript text for the active video when available
  • Video title and description only when you explicitly allow fallback text in advanced flows
  • Extension settings, compact report metadata, and session handoff state stored through Chrome extension storage
How it is used

Why the extension uses that data

  • Show the inline Analyze video button on supported YouTube watch pages
  • Retrieve the strongest transcript path available for the active video
  • Generate a verdict, score, explanation, and transcript-quality summary for that video
  • Open the side-panel workspace when you explicitly ask for deeper review
Local storage

What ScriptLens stores locally

  • Extension settings such as sensitivity, maximum text length, and debug mode
  • A short recent-report history so the popup and workspace can show prior checks
  • Dismissed UI hints and small session values used to pass the active video into the side panel
  • Optional debug summaries when debug mode is enabled

ScriptLens does not intentionally store full transcript text in its recent-report history.

Not collected

What the normal flow avoids

  • No transcript text, score, or report is sent to ScriptLens or any third party
  • No account login or cloud identity is required to use the extension
  • No browsing history outside supported YouTube pages is collected
  • No payment data, health data, passwords, or personal communications are collected
  • No selling of user data and no advertising use of collected data
Network requests

When the extension uses the network

To read a transcript, ScriptLens requests caption and transcript data for the active video from https://www.youtube.com. These requests go only to YouTube, use your existing YouTube session like the YouTube page itself, and are subject to YouTube's own privacy policy.

ScriptLens does not operate a backend, does not use analytics or telemetry, and does not send transcript text, scores, reports, or identifiers to any server. Scoring runs inside the extension on your device.

Permissions and control

Why the extension asks for permission

  • storage to save settings, recent report summaries, and small session handoff state
  • sidePanel to open the advanced workspace view when you request it
  • YouTube host access on https://www.youtube.com/* to read supported watch-page content
Support and policy updates

Questions about privacy or data flow?

Use the public support route if you need clarification about how the extension handled a YouTube video or how it treats your data.
